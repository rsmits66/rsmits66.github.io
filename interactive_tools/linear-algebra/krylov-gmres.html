Krylov Spaces · Arnoldi Iteration · GMRES

Solving Ax=b via orthonormal Krylov bases — 4 iterations on a 6×6 system
★ System — edit A and b, then run
MATRIX A (6×6)
VECTOR b
1 The Krylov Space Km(A,b)
Idea: Instead of solving Ax=b in all of ℝ⁶, seek the best approximate solution in the Krylov subspace — spanned by b, Ab, A²b, … The Arnoldi process builds an orthonormal basis for this space one vector at a time.
2 Starting vector q₁ = b / ‖b‖
q₁ is the unit vector in the direction of b. It seeds the Arnoldi process.
3 Arnoldi Iteration — building Q and the upper Hessenberg H
At each step j: multiply by A, subtract projections onto all previous q's (modified Gram-Schmidt), normalise to get q_{j+1}. The coefficients collected give column j of H.
4 The relation A Q₄ = Q₅ H̃  (and Q₄ᵀA Q₄ = H₄ approximately)
H̃ — upper Hessenberg (5×4)
H₄ = Q₄ᵀ A Q₄ (4×4, top block of H̃)
5 GMRES — Minimise ‖H̃y − ‖b‖e₁‖ over y ∈ ℝ⁴
Least-squares system H̃y = β e₁
Optimal y₄ (least-squares solution)
6 Solution x₄ = Q₄ y₄ and residual r₄ = b − A x₄
x₄ = Q₄ y₄
Residual r₄ = b − Ax₄
